# norabu_frames

Unit frames for the World of Warcraft Classic client, with a classic layout and a thick, soft black border.

## What it does

- Restyles the player, target, target-of-target, focus and pet frames, keeping Blizzard's own frames underneath so clicking, menus, auras and Edit Mode positioning still work.
- Thick merged health bar with a thin power bar, class and reaction colours, and the unit name above the frame.
- Class icons on players, with the normal portrait for NPCs. The pet and focus have no portrait.
- Elite, rare and boss artwork around the target icon.
- Incoming-heal prediction, and a mana-cost preview while you cast.
- Your own target and focus cast bars: icon, spell name, time left, and a gray tint for casts that can't be interrupted.
- Bar text you can configure for each frame: raw value, abbreviated, percent, or a combination, placed left, centre or right, with its own size sliders for health and power.
- A druid's mana bar under the power bar while in cat, bear or dire bear form, with the same text options.

## Install

1. Download this repo.
2. Copy the `norabu_frames` folder into your `Interface/AddOns` folder.
3. Start the game, or type `/reload`.

## Settings

Type `/nf` or `/norabu`, or find **norabu_frames** under Esc > Options > AddOns. You can change the bar texture, class icon set, elite art style, cast bar position, bar sizes and bar text. Everything applies immediately, and **Reset to defaults** puts it all back.

Frame positions are set in Blizzard's Edit Mode, as usual.

## Compatibility

- Built for the client with interface version 16001 (the classic beta / Forever client).
- It does not run alongside **ClassicFrames** or **StormxUI**'s unit frames. If either is enabled, norabu_frames prints a message and stands down.
